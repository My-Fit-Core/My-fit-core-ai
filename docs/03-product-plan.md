## 제품 한 줄 요약

내 옷장 옷을 한 번에 찍어 디지털화하고, 날씨 × 추구미(Aesthetic) × 일정(TPO)에 맞춰 매일 코디 3종을 추천하며, 다른 사람의 OOTD를 내 옷으로 따라 입게 해주는 앱.

## 타겟

- 주: 마이크로 코어(Aesthetic) 문화를 즐기는 1020대 여성
- 보조: 아침 준비 시간을 줄이고 싶은 2030 직장인·대학생

## 해결하는 문제 → AI가 맡는 해법

| 문제 | 해법 | AI 기능 |
| --- | --- | --- |
| 옷 한 벌씩 등록하는 피로 | 여러 벌 원샷 촬영 + 자동 분할·태깅 | F-201, F-202, F-203 |
| 천편일률적 날씨 추천 | 15대 추구미 반영 추천 | F-302, F-303 |
| 혼자 쓰는 툴의 낮은 재방문 | 타인 OOTD를 내 옷장으로 따라입기 | F-402 |

## 승인 조건 (AI 관련)

1. 다중 의류 촬영 시 최대 6벌까지 2초 이내 객체 분할, 카테고리 분류 정확도 90% 이상
2. 선택한 추구미와 날씨에 맞는 코디가 매일 오전 7시 홈에 에러 없이 렌더링
3. OOTD 클릭 시 본인 옷장 아이템과의 매칭률(%) 계산 및 대체 추천 동작

## 관련 KPI

- 다중 의류 등록 완료율 75% 이상 (분할 결과 확인 후 저장까지)
- 일일 코디 채택률 40% 이상

## 역할 경계

- AI: 검출·누끼·태깅 파이프라인과 서빙, 추천 알고리즘, LLM 프롬프트, 유사도 검색
- 백엔드: 스토리지·DB·작업 큐, 기상청 API·캐시, 7시 배치 트리거, 인증
- 프론트: 촬영 가이드 UI, 일괄 편집 UI, 추천 카드·스왑 UI
