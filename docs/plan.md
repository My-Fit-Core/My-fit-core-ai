## 1. 한 줄 목표

내 옷장 옷을 사진 한 장으로 등록(검출·누끼·태깅)하고, 날씨 × 추구미 기반 코디 3종과 슬롯 교체 후보를 추천하는 AI 서버를 남은 3주(11/23 기준, 마감 약 12/14 `[가정]`) 안에 MVP로 완성한다.

기한이 짧아 추구미는 원안 15종이 아니라 **기본 5개를 제대로 구현하는 것**에 집중한다. 나머지는 2차 로드맵이다(팀 합의).

## 2. 구조와 기술 스택

```
[앱] → [Supabase Storage] → [백엔드(Supabase+Vercel)] --job--> [AI 서버(이 레포)]
```

| 영역 | 확정 | 미정 |
| --- | --- | --- |
| 언어·서빙 | Python 3.11, FastAPI + Uvicorn, Docker 이미지 하나 | 서빙 플랫폼 (Modal / RunPod / 직접) |
| 검출 | YOLO (DeepFashion2, `deepfashion2_yolov8s-seg.pt`), 부위 판정도 YOLO 클래스 | - |
| 분할·누끼 | YOLO 자체 마스크 + 구멍 메우기 | SAM 2.1 tiny 추가 여부 (Flat Lay 비교 후) |
| 태깅 | FashionCLIP zero-shot. 입력은 마스크 밖을 흰색으로 지우고 박스로 자른 사진. 색상은 마스크 픽셀 k-means | 카테고리 세부 체계 |
| 추구미 점수 | 옷 한 벌 `prompts.item`(보정 없음), 코디 사진 `prompts.outfit`(고정 prior 보정) | - |
| 추천 | 규칙 기반 점수 함수 `recommend/`, GPU 불필요 | 실행 위치(AI 서버 API vs 백엔드), 동기 여부 |
| LLM 코멘트(P1) | 경량 LLM API | 모델 |
| 벡터 | 백엔드 Supabase pgvector | 임베딩 응답 포함 여부 |

- 코드 규칙: ruff, 타입 힌트, pydantic 요청/응답, 모델은 서버 시작 시 1회 로드, 비밀값은 환경변수.
- 라이선스: DeepFashion2 가중치는 비상업용. 공개 서비스 전에 교체 또는 허용 여부 확인 `[미정]`.

## 3. MVP 범위

포함 (P0)
- F-201 다중 의류 원샷 검출 (최대 6벌)
- F-202 인스턴스 분할·누끼
- F-203 속성(카테고리·색·패턴)·추구미 자동 태깅·임베딩
- F-302 날씨 × 추구미 추천 엔진 (코디 3종, 서로 다양하게)
- F-304 코디 슬롯 교체 후보 랭킹

포함 (P1, 오픈 베타 전. 시간 부족하면 여기서 자른다)
- F-303 LLM 스타일리스트 코멘트
- F-402 내 옷장으로 따라입기 (유사도 매칭률)

제외 (2차 로드맵)
- TPO(출근·데이트 등). 1차는 날씨 + 추구미만.
- 원안 15종 추구미와 마이크로 트렌드(Y2K, 모리걸 등). 3주 기한 때문에 기본 5개만 구현하고, 나머지는 그 위에 추가한다(목록은 `configs/aesthetics.yaml` 설정으로 받는 구조 유지).
- SAM 추가 검토(#41 비교)는 시간이 남을 때만. 기본은 YOLO 마스크.
- 남성 타겟 구현(아키텍처만 확장 가능하게, 구현은 2차).
- 퍼스널컬러·체형 분석(하지 않기로 결정).
- 옷 종류 영향 제거 보정, linear probe(#34), 색 기반 추구미 보정(검증 실패, #50).

## 7. 예외·실패 처리 (구현 시 반드시 포함)

- 검출 0벌 또는 저신뢰: `[제안]` 빈 `items`로 성공 처리하지 않고 사용자가 알 수 있는 오류 코드를 반환(형식은 API v1에서 확정).
- 7벌 이상: `max_items`(1~6) 기준 상위 신뢰도만 반환.
- 이미지 규격 위반(형식·크기·EXIF): `failed` + 사유. 짧은 변 <512px는 경고.
- 카테고리 확신 낮음: 상위 3개 후보를 모두 반환(사용자 수정).
- 옷장이 부족해 코디 3종을 못 만듦(예: 하의 없음): 가능한 만큼 반환하고 사유를 포함.
- 날씨 입력 결측: 기본 규칙으로 대체하고 결과에 표시.
- 옷 종류 쏠림으로 한 스타일 코디만 추천되는 편향: 세트 간 다양성 규칙으로 완화.
- 모델 로드 실패·타임아웃: `/health`에 반영, 요청은 `failed`.

## 8. 팀 결정이 필요한 것 `[미정]`

- 서빙 플랫폼·비용
