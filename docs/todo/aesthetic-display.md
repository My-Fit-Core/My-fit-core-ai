## 맥락

- Lekondo 앱은 결과를 스타일 하나로 단정하지 않고 여러 스타일의 비율과 반대 개념 축 3개로 보여준다. 스타일 설명은 실루엣·색·핵심 아이템 위주다.
- zero-shot은 세부 스타일 구분이 불안정하고 미니멀로 쏠린다(`261101-0002-03-aesthetic-style-mapping.md`).
- 프롬프트를 고치는 실험이라 기존 시드 42가 아닌 시드 7 표본으로 측정한다(`docs/04-kfashion-validation.md`).
- 색상 추출과 LLM 코멘트는 누끼(Vision PoC)와 F-303 이후로 미룬다.
