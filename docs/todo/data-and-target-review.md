## 목표

추구미 5개(페미닌, Y2K, 미니멀, 빈티지 레이어드, 캐주얼)에 맞는 현재 트렌드 이미지 데이터를 확보한다. 특히 Y2K는 AI Hub K-Fashion에 대응 스타일이 없어 직접 수집이 필요하다.

## 완료 조건

- [ ] 추구미별로 현재 트렌드를 반영한 이미지 데이터 출처 확인 (저작권 포함)
- [ ] Y2K 데이터 수집 경로 확정 (크롤링 / 공개 데이터셋 / 기타)
- [ ] 온보딩 화면용 추구미별 3장 × 5개 = 총 15장 최종 선정 (261109 확정 수치)

## 맥락

11/9 회의에서 디자인 참고용 패션 이미지가 "5년 전 옷"이라 현재 트렌드와 맞지 않는다는 문제가 제기됐다. AI Hub K-Fashion 데이터도 같은 한계(`docs/04-kfashion-validation.md` — Y2K 대응 스타일 없음).

**타겟층(현재 2030) 변경은 데이터를 최대한 찾아본 뒤에도 적합한 데이터를 확보할 수 없을 때의 최후 수단이다.** 먼저 데이터 수집을 시도하고, 그래도 안 될 경우에만 팀 전체 논의를 거쳐 3040으로 변경한다.
