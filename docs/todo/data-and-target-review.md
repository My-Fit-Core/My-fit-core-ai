# 데이터 소스 재검토 & 타겟 연령층 확정

- 상태: 대기
- 담당: AI 파트 + 전체 팀
- 관련 기능 ID: F-201, F-203, F-302
- 시작일:
- 완료 Report:

## 목표

온보딩·추구미 추천에 쓸 참고 이미지와 AI 모델 학습 데이터가 현재 트렌드를 반영하는지 확인하고, 타겟 사용자 연령층(현재 2030)을 확정한다.

## 완료 조건

- [ ] 현재 AI Hub K-Fashion 데이터의 트렌드 적합성 판단(연도·스타일 분포)
- [ ] Y2K 추구미 대응 데이터 확보 경로 결정 (직접 크롤링 / 외부 데이터셋 / 추구미 목록에서 제외)
- [ ] 타겟 연령층 2030 vs 3040 팀 최종 합의
- [ ] 결정 사항을 `02-specs.md` §4에 반영

## 맥락

11/9 회의에서 디자인 참고용으로 사용하던 패션 이미지 데이터가 "5년 전 옷"이라는 문제가 제기됐다. 특히 Y2K 스타일이 현재 트렌드와 다르고(`docs/04-kfashion-validation.md` — "K-Fashion에 대응 스타일이 없어 직접 수집 필요"), AI Hub K-Fashion 데이터 자체도 같은 한계를 가질 수 있다.

타겟층을 3040으로 바꾸면 기존 데이터가 오히려 더 적합할 수 있다는 의견이 나왔으나, 페르소나와 기획 전반에 영향을 주므로 팀 합의가 필요하다.

## 열린 질문

- [ ] Y2K를 추구미 5개에 계속 포함할 것인가? 포함 시 데이터를 어디서 가져오는가?
- [ ] 타겟층을 2030으로 유지하면 AI Hub 데이터 외에 현재 트렌드 데이터를 어디서 보완할 것인가?
- [ ] 타겟층을 3040으로 바꾸면 `02-specs.md` §4(타겟), `03-product-plan.md`, 페르소나 문서를 모두 수정해야 한다. 범위가 크므로 확정 전에 팀 전체 동의 필요.
