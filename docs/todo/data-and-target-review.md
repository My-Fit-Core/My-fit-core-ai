## 맥락

11/9 회의에서 디자인 참고용 패션 이미지가 "5년 전 옷"이라 현재 트렌드와 맞지 않는다는 문제가 제기됐다. AI Hub K-Fashion 데이터도 같은 한계(`docs/04-kfashion-validation.md` — 오래된 데이터, 스트리트는 힙합·스포티로 잠정 연결).

**타겟층(현재 2030) 변경은 데이터를 최대한 찾아본 뒤에도 적합한 데이터를 확보할 수 없을 때의 최후 수단이다.** 먼저 데이터 수집을 시도하고, 그래도 안 될 경우에만 팀 전체 논의를 거쳐 3040으로 변경한다.

## 진행 메모

- 2026-11-26: 요즘 스타일 레퍼런스 사진을 `data/reference_styles/`(레포에 안 올림)에 모으는 중. `labels.csv`는 7종 추구미 칸(1/0, 여러 개 가능) + `sub_tag`(하위 태그) + `off_shoulder` + 체크리스트·메모
  - 미니멀 20장(핀터레스트 검색어: 미니멀·모노톤·클린걸·올드머니 각 4~6장). 정답은 **검색어 기준이라 섞였을 수 있다**(`labeler`에 "핀터레스트 검색어(미검증)"). 오피스/클래식·빈티지 레이어드와 겹쳐 보이는 사진은 메모에 적었다
  - **하위 태그는 기록만 한다.** 측정·문장 다듬기는 7종 메인 스타일로만 한다(하위 태그는 제안서대로 나중에 규칙으로 붙임)
  - 정답으로 쓰기 전에 다른 팀원 한 명이 검색어를 모른 채 다시 분류해 두 사람이 같은 것만 쓴다(Report `261125-2258-01` §7-1)

- 2026-11-26: 캐주얼 20장(핀터레스트 검색어: 캐주얼·꾸안꾸·데님룩·캠퍼스룩·애슬레저). 사진에 모자가 있으면 얼굴만 흐리게 하고 모자는 남긴다(모자도 스타일 단서)
  - **꾸안꾸 하위 태그는 지운다**(사용자 결정 11/26): 캐주얼과 거의 같아 따로 둘 이유가 적다. 꾸안꾸로 모은 사진은 `sub_tag`를 캐주얼로 바꿨다
  - 캐주얼 하위 태그는 분위기가 아니라 아이템으로 갈린다. 나중에 규칙으로 붙일 때 후보: 데님룩 = 캐주얼 + 데님 소재 옷 2벌 이상, 캠퍼스룩 = 캐주얼 + 백팩·토트백, 애슬레저 = 캐주얼 + 운동복 계열(트랙 재킷·조거, 지금 소분류에 없음)

- 2026-11-27: 레퍼런스 사진 총 185장(미니멀 20, 캐주얼 20, 러블리/페미닌 20, 걸리시 스트릿 32, Y2K/빈티지 40, 오피스/클래식 20, 보헤미안 29, 겹침 포함). 정답은 검색어 기준(미검증)
- 2026-11-27: **소분류 `midi_skirt` 추가**(사용자 결정). 빈티지·모리걸·오피스에서 많이 입고, 언발란스 스커트도 대부분 미디 기장이라 비대칭 디테일 대신 기장으로 처리. 판정 문장은 사용자 기준(양쪽 무릎이 다 보이면 미니, 무릎~종아리 미디, 종아리를 다 덮으면 롱)
  - 레퍼런스 사진 10장 확인(미검증 수준): 미디 6장은 모두 midi 1위. 미니 1장(바지처럼 보이는 스커트)·롱 1장은 midi 1위, 정답은 2위. **미디 쪽으로 쏠림**이 있어 T1 사진으로 다시 본다
  - 추천 `warmth`에 `midi_skirt: 1`(롱스커트와 같게) 초안 추가. 상의 + 미디 스커트 + 바지 레이어드, 비 오는 날 규칙 등은 추천 담당에게 전달함(사용자 11/27)
  - 프론트·백엔드 소분류 목록에 "미디 스커트" 추가 필요
