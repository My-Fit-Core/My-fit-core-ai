## Flat Lay 촬영 체크리스트 (T1)

근거: `docs/reports/261125-2258-01-mentoring-feedback-ai-plan.md` §2, §7-1, §9-3. 공개 데이터에 없는 경우는 **직접 만들어 찍는다.** 사진마다 정답(대분류·소분류·핏·오프숄더 여부)을 같이 적는다.

| 넣을 것 | 장수 | 확인하는 것 |
| --- | --- | --- |
| 기본: 상의·하의·아우터·원피스 섞어 2~6벌 | 15~20 | 검출·카테고리 정확도, 6벌 2초 |
| 오프숄더·원숄더 상의 | 3~5 | `off_shoulder` 판정 |
| 오버사이즈 아우터(어깨 내려온 코트·무스탕) vs 어깨선 잡힌 블레이저·재킷 | 3~5 | 아우터 `fit` 판정 |
| 와이드·스키니·일자 바지 | 3~5 | 하의 `fit` 판정 |
| 오버핏 vs 레귤러 상의 | 3~5 | 상의 `fit` 판정(어려울 것으로 예상) |
| 스카프·넥 스트랩을 상의 목 부분에 **겹쳐** 놓기 / 떨어뜨려 놓기 | 2~3씩 | 겹침이 상의 마스크·오프숄더 판정을 흔드는지 |
| 넥 밴드가 붙은 오프숄더 니트처럼 판정이 헷갈릴 옷 | 있으면 1~2 | 어려운 예 |

- 스카프가 없으면 비슷한 얇은 천으로 대신해도 된다. 촬영 가이드가 "겹치지 않게"를 안내하므로 겹친 예는 소수로 충분하다.
- 한 장에 여러 경우를 섞어도 된다(예: 오프숄더 상의 + 와이드 바지 + 블레이저).
