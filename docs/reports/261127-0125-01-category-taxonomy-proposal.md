## 배경

`configs/categories.yaml`은 T2 미확정 상태이고, `bag` 소분류는 `category-taxonomy.md`에서 "세부는 새 제안"으로 열어 두었다.
현재 `accessory`의 소분류가 `hat`, `scarf`, `jewelry` 3종뿐이라 추천 엔진에서 추구미별 조합 보너스(B안)를 설계할 때 신호가 부족하다.
이 보고서는 HandoA01이 추천 담당 관점에서 소분류 확장 방향을 제안하는 것이며 **팀 결정은 별도로 받는다.**

## 제안 내용

### 1. 가방 소분류 4→8종 확장

현재: `shoulder_bag`, `tote_bag`, `backpack`, `crossbody_bag`

| 소분류 | 설명 | 비고 |
| --- | --- | --- |
| `mini_bag` | 미니백·포켓백. 페미닌·Y2K에 보너스 | 신규 |
| `shoulder_bag` | 숄더백 | 유지 |
| `tote_bag` | 에코백·토트백 | 유지 |
| `backpack` | 백팩 | 유지 |
| `crossbody_bag` | 크로스백·메신저백 | 유지 |
| `bucket_bag` | 버킷백 | 신규 |
| `waist_bag` | 웨이스트백·힙색 | 신규 |
| `clutch` | 클러치·파우치백 | 신규 |

> 버스턴/더플백, 웨이스트백(체육복용)은 패션 등록 빈도가 낮아 제외.

### 2. 모자(`hat`) 대분류 승격

현재 `accessory`의 소분류 → 별도 대분류 `hat`으로 분리.

이유: 모자는 머플러·목도리처럼 2종으로 끝나는 아이템이 아니고, 추구미별 조합 보너스 신호가 뚜렷하다.
악세서리로 묶으면 소분류가 너무 많아져 태깅 경합이 생긴다.

| 소분류 | 추구미 신호 |
| --- | --- |
| `baseball_cap` | 캐주얼·스트리트 |
| `bucket_hat` | Y2K·보헤미안 |
| `beanie` | 캐주얼·스트리트·미니멀 |
| `beret` | 페미닌·오피스 |
| `wide_brim_hat` | 보헤미안·페미닌 |

### 3. 악세서리 소분류 확장 → 8종

현재: `hat`, `scarf`, `jewelry` → 모자를 대분류로 빼고 아래로 확장.

| 소분류 | 비고 |
| --- | --- |
| `scarf` | 스카프 |
| `muffler` | 머플러·목도리. warmth 신호 겸용 가능 |
| `belt` | 벨트 |
| `leg_warmers` | 레그워머. warmth 신호 겸용 가능. Y2K·보헤미안 |
| `tights` | 스타킹·타이츠. 페미닌·오피스 |
| `socks` | 양말(발목·크루 포함). 조합 보너스 룰 없음, 등록만 |
| `eyewear` | 선글라스·안경 |
| `jewelry` | 목걸이·귀걸이·반지 등 |

> 시계: AI가 주얼리와 구분하기 어렵고 조합 설계가 복잡해져 현재 단계에서는 별도 소분류 없이 `jewelry`에 포함.
> 양말 세부 소분류(크루삭스·무릎양말 등)는 AI 판정이 전신샷에서 어려워 미분류.

## 추구미 × 소분류 조합 보너스 설계 의견 (B안)

이 보고서는 소분류 목록 제안이 주목적이므로 **조합 보너스 가중치 수치는 포함하지 않는다.** 방향만 적는다.

- 가방·모자·악세서리 소분류 확정 후 `configs/recommend.yaml`에 `subcategory_bonus` 블록 추가를 제안
- 예시: `casual` 추구미는 `tote_bag`, `backpack`에 가중치 +, `clutch`에 -
- `leg_warmers`, `muffler`는 `warmth` 점수와 겸용: 보너스와 별개로 날씨 조건에도 반영 가능
- 소분류가 `accessory` 단위로만 있으면 추구미별 미세 조정이 불가능 → 소분류 확장이 선행 조건

수치 설계는 소분류 확정 후 별도 보고서로 제출.
