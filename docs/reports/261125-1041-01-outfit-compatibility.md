## 요약

K-Fashion 착용 사진에서 같은 사진의 상의·하의를 "함께 입은 쌍"으로, 다른 사진의 하의를 붙인 쌍을 negative로 두고 FashionCLIP 임베딩만으로 어울림을 구분할 수 있는지 쟀다. 학습 없는 cosine은 AUC 0.66~0.68, 로지스틱 회귀(LR)는 AUC 0.79~0.81로 우연(0.5)보다 분명히 높았다. 같은 스타일 안에서 negative를 뽑아도(hard) LR AUC 0.77~0.79, FITB@10 39~40%(우연 10%)로 유지돼 "스타일이 같아서 맞히는 것"만은 아니다. **다만 positive가 같은 사진에서 나와 조명·화질이 같으므로, "어울림"이 아니라 "같은 사진"을 맞힌 몫이 얼마인지는 이 실험으로 가릴 수 없다.** hard FITB에서 LR이 cosine보다 7%p 높았고, 이번 실험 설계 때 세운 초안 기준(10%p, 문서 근거 없음)에는 못 미쳤다. 추천에 붙일지는 사람이 정한다.

## 실험 조건

- 데이터: K-Fashion Validation, 상의·하의 박스와 폴리곤이 모두 있는 사진 5,000장(라벨 순서를 시드 42로 섞어 앞에서부터). Windows CPU.
- 크롭: 라벨 폴리곤 마스크 밖을 흰색으로 지운 박스 크롭(`app.pipeline.tagging.crop_item`, 서비스 입력과 같은 형식). 임베딩 FashionCLIP 512차원, 장당 0.33초(상의·하의·아우터 배치).
- 거의 같은 사진 묶음: 상의 cosine과 하의 cosine이 둘 다 0.95 이상이면 같은 묶음 `[초안]`. 5,000장 → 4,997묶음(6장이 여러 장 묶음에 속함). 묶음 단위로 train 80% / test 20%, 분할 시드 42·7.
- 학습: positive 1 : negative 4 `[초안]`(같은 split 안의 다른 사진 하의). LR 입력 `[a, b, a*b, |a-b|]`(2048차원), `C=1.0`.
- 평가 negative: random(test 안의 다른 사진 하의), hard(같은 K-Fashion 주 스타일 안의 다른 사진 하의). FITB@10 = 정답 하의 1 + 다른 하의 9 중 정답 1위 비율.
- 표본 스타일 분포: 스트리트 2,660(53%), 모던 406, 페미닌 383, 로맨틱 355, 리조트 333, 소피스트케이티드 187, 컨트리 140, 클래식 117, 그 밖 14개 스타일과 라벨 없음 4장.

## 결과

| 지표 | 우연 | cosine (시드 42 / 7) | LR (시드 42 / 7) |
| --- | ---: | ---: | ---: |
| AUC random | 0.5 | 0.682 / 0.665 | **0.815 / 0.795** |
| AUC hard (같은 스타일) | 0.5 | 0.661 / 0.652 | **0.786 / 0.769** |
| FITB@10 random | 10% | 33.4% / 33.3% | **44.0% / 41.4%** |
| FITB@10 hard | 10% | 32.4% / 31.9% | **39.7% / 38.5%** |

- test 999 / 1,001장, FITB 문항 random 999 / 1,001개, hard 957 / 960개(같은 스타일 후보가 9개 미만인 상의는 뺌).
- 아우터 쌍(아우터가 있는 363장, cosine만): 아우터-상의 AUC 0.651, 아우터-하의 AUC 0.684.
- 서비스 입력(YOLO 검출 크롭)으로 바꿨을 때(시드 7 분할의 test 중 상의·하의를 둘 다 찾은 300장):

  | | AUC random |
  | --- | ---: |
  | LR, 라벨 크롭(같은 300장) | 0.798 |
  | LR, YOLO 크롭 | 0.752 |
  | cosine, YOLO 크롭 | 0.632 |

  YOLO 부위 판정이 라벨 부위와 맞은 비율 98.2%, 라벨 크롭과 YOLO 크롭 임베딩의 평균 cosine 0.920. 검출 크롭으로 바꾸면 LR AUC가 약 0.05 떨어진다.

## 해석과 한계

- hard에서도 우연보다 크게 높다 → 스타일 라벨이 같은 옷끼리도 "함께 입은 쌍"을 어느 정도 구분한다.
- **같은 사진 지름길 위험**: positive는 같은 사진에서 나와 조명·화이트밸런스·화질이 같다. 모델이 "어울림"이 아니라 "같은 사진"을 맞힌 것일 수 있다. 흰 배경 처리로 줄였지만 없앤 것은 아니다. 이 실험만으로는 둘을 구분할 수 없다(대조 실험 필요, 아래 후속).
- **스타일 쏠림**: 표본의 53%가 스트리트라 hard negative도 대부분 스트리트 안에서 뽑혔다. 스타일별 수치는 n이 작은 스타일이 많아 이번에는 보지 않았다.
- **도메인 차이**: 착용 사진(사람이 입은 옷)으로 학습했다. 서비스 옷장은 Flat Lay·단독 사진이라 분포가 다르다. 검출 크롭만 바꿔도 AUC가 0.05 떨어졌다.
- **같은 인물·같은 코디의 다른 컷 누수**: 거의 같은 사진 묶음 기준(상의·하의 cosine 둘 다 0.95 이상)에 걸린 사진은 5,000장 중 6장뿐이었다. 같은 인물이나 같은 코디를 다른 각도로 찍은 사진은 이 기준으로 거의 걸러지지 않으므로 train/test에 걸쳤을 수 있고, 그만큼 점수가 부풀려졌을 수 있다(정도는 미측정).
- 다음 단계 판단 기준 `[초안]`: 이번 실험 설계 때 세운 기준(문서·회의 근거 없음). "LR hard FITB가 cosine보다 10%p 이상, hard AUC 0.65 이상이면 추천에 붙이는 후속을 제안" → hard AUC는 충족(0.77~0.79), FITB 차이는 7%p로 미충족.

## 주요 결정

| 결정 | 근거 | 대안과 버린 이유 |
| --- | --- | --- |
| 학습·평가는 라벨 폴리곤 크롭 | 검출 오류가 섞이지 않게. 서비스 입력과의 차이는 YOLO 크롭 300장으로 따로 잼 | 처음부터 YOLO 크롭: 검출 실수와 모델 성능이 섞임 |
| 이미지(거의 같은 사진 묶음) 단위 분할 | 같은 사진이 train/test에 걸치면 점수가 부풀려짐. K-Fashion에 인물 ID가 없어 임베딩 유사도로 대신했지만, 같은 인물의 다른 컷은 거의 못 거름(한계 참고) | 쌍 단위 무작위 분할: 누수 |
| 모델은 cosine과 LR만 | 최소한으로 신호가 있는지부터 확인 | MLP·파인튜닝: 이번 범위 밖 |
| 표본 5,000장 | 계획 초안 2,000장 기준 예상(1초/벌)보다 실제가 빨라(장당 0.33초) 같은 시간에 더 많이 | 2,000장: hard FITB 문항이 적어짐 |
| 사진 zip이 없으면 풀어 둔 jpg를 읽음 | 로컬 데이터는 zip을 풀고 지운 상태 | 기존 `pick_samples` 재사용: zip 필수라 실행 불가 |

## 후속 작업 (결정은 사람)

- **같은 사진 지름길 대조 실험** (추천에 붙이기 전에 권장): negative를 "같은 사진 속 다른 사람의 하의"로 쓸 수는 없으므로, 대신 (1) 크롭을 흑백·색 보정으로 바꿔도 점수가 유지되는지, (2) 색·밝기 통계만으로 같은 수준이 나오는지 비교해 지름길 비중을 잰다.
- 추천(T14 `recommend/scoring.py`)에 붙인다면: 상의·하의 쌍 점수로 `weights`에 `compatibility` 항을 추가하는 방식(설정에서 가중치 0이면 꺼짐). 아우터 쌍은 학습 표본이 적어 cosine만 쓰거나 제외.
- Flat Lay 사진(T1)이 생기면 YOLO 크롭 기준으로 다시 확인.
- 대학원생 자문 때 "착용 사진 co-occurrence로 학습한 어울림 모델이 Flat Lay 옷장에도 통할지" 의견 듣기.
