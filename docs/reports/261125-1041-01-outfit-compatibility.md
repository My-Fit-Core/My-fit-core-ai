## 요약

K-Fashion 착용 사진에서 같은 사진의 상의·하의를 "함께 입은 쌍"으로, 다른 사진의 하의를 붙인 쌍을 negative로 두고 FashionCLIP 임베딩만으로 어울림을 구분할 수 있는지 쟀다. 학습 없는 cosine은 AUC 0.66~0.68, 로지스틱 회귀(LR)는 AUC 0.79~0.81로 우연(0.5)보다 분명히 높았다. 같은 스타일 안에서 negative를 뽑아도(hard) LR AUC 0.77~0.79, FITB@10 39~40%(우연 10%)로 유지돼 "스타일이 같아서 맞히는 것"만은 아니다. **같은 사진이라 조명이 같아서 맞힌 것 아니냐는 의문을 대조 실험(같은 날 16:18 추가)으로 일부 확인했다. 색 히스토그램 모델 기준으로, 사진 전체로 조명 색을 보정해도 점수가 거의 그대로(LR hard AUC 0.790/0.761 → 0.774/0.745)라 조명 색조 몫은 작다. 색을 모두 뺀 흑백 CLIP도 hard AUC 0.71~0.72로 우연보다 높아 모양·질감 신호도 있다.** 다만 남은 색 신호가 "옷끼리의 색 관계"인지, 화이트밸런스로 지워지지 않는 같은 사진의 밝기·채도·화질 단서인지는 가리지 못했다. CLIP 모델에서의 사진 전체 기준 조명 보정과 같은 인물의 다른 컷 누수도 남은 한계다. hard FITB에서 LR이 cosine보다 7%p 높았고, 이번 실험 설계 때 세운 초안 기준(10%p, 문서 근거 없음)에는 못 미쳤다. 추천에 붙일지는 사람이 정한다.

## 실험 조건

- 데이터: K-Fashion Validation, 상의·하의 박스와 폴리곤이 모두 있는 사진 5,000장(라벨 순서를 시드 42로 섞어 앞에서부터). Windows CPU.
- 크롭: 라벨 폴리곤 마스크 밖을 흰색으로 지운 박스 크롭(`app.pipeline.tagging.crop_item`, 서비스 입력과 같은 형식). 임베딩 FashionCLIP 512차원, 장당 0.33초(상의·하의·아우터 배치).
- 거의 같은 사진 묶음: 상의 cosine과 하의 cosine이 둘 다 0.95 이상이면 같은 묶음 `[초안]`. 5,000장 → 4,997묶음(6장이 여러 장 묶음에 속함). 묶음 단위로 train 80% / test 20%, 분할 시드 42·7.
- 학습: positive 1 : negative 4 `[초안]`(같은 split 안의 다른 사진 하의). LR 입력 `[a, b, a*b, |a-b|]`(2048차원), `C=1.0`.
- 평가 negative: random(test 안의 다른 사진 하의), hard(같은 K-Fashion 주 스타일 안의 다른 사진 하의). FITB@10 = 정답 하의 1 + 다른 하의 9 중 정답 1위 비율.
- 표본 스타일 분포: 스트리트 2,660(53%), 모던 406, 페미닌 383, 로맨틱 355, 리조트 333, 소피스트케이티드 187, 컨트리 140, 클래식 117, 그 밖 14개 스타일과 라벨 없음 4장.

## 대조 실험: "같은 사진" 지름길 확인 (2026-11-25 16:18 추가)

같은 5,000장, 같은 분할(raw 임베딩 기준 묶음)에서 옷 특징만 바꿔 LR을 다시 학습·평가했다.

| 특징 | 무엇을 뺐나 | LR AUC hard (42 / 7) | LR FITB@10 hard | cosine AUC hard |
| --- | --- | ---: | ---: | ---: |
| raw: CLIP, 원래 크롭 | - | **0.786 / 0.769** | 39.7% / 38.5% | 0.661 / 0.652 |
| graywb: CLIP, 옷 픽셀 기준 화이트밸런스 | 조명 색 + 옷 자체 색 상당 부분 (아래 주의) | 0.743 / 0.726 | 34.0% / 30.6% | 0.634 / 0.615 |
| gray: CLIP, 흑백 | 색 전부 | 0.722 / 0.713 | 31.8% / 28.2% | 0.609 / 0.598 |
| color: HSV 색 히스토그램(CLIP 없음) | 모양·질감·무늬 | **0.790 / 0.761** | 40.9% / 37.2% | 0.723 / 0.700 |
| colorwbimg: 사진 전체 기준 화이트밸런스 뒤 색 히스토그램 | 모양 + 사진 조명 색감 | **0.774 / 0.745** | 41.4% / 35.5% | 0.716 / 0.687 |
| colorwb: 옷 픽셀 기준 화이트밸런스 뒤 색 히스토그램 | 모양 + 옷 자체 색 상당 부분 | 0.695 / 0.686 | 27.2% / 24.8% | 0.592 / 0.575 |

- 우연 수준: AUC 0.5, FITB@10 10%.
- random negative에서는 raw CLIP이 색 히스토그램보다 조금 높다: LR AUC random raw 0.815/0.795, color 0.798/0.772, colorwbimg 0.779/0.755, gray 0.749/0.735. hard에서는 시드 42에서 color(0.790)가 raw(0.786)보다 높다.
- 색 히스토그램: 옷 마스크 안 픽셀 HSV 8×4×4칸 `[초안]`. 화이트밸런스는 gray-world(채널 평균을 같게).
- **설계 실수와 바로잡기**: 처음 만든 `graywb`·`colorwb`는 화이트밸런스를 옷 한 벌 픽셀로만 맞춰, 조명 색감뿐 아니라 옷 자체 색(빨간 셔츠 → 회색 쪽)까지 지웠다. 그래서 이 둘은 "조명만 뺀 대조"로 읽으면 안 된다. 조명은 사진 전체에서 추정해야 해서 `colorwbimg`를 추가했다. CLIP의 사진 전체 기준 보정(`graywbimg`)은 돌리지 않았다.

해석
- **조명 색조 지름길은 작다(색 히스토그램 모델 기준)**: 사진 전체로 조명 색을 보정해도 LR hard AUC가 0.790/0.761 → 0.774/0.745(약 0.016)로 거의 그대로다. gray-world는 채널별 곱셈 보정이라 색조(빛 색깔)만 빼고, 같은 사진의 밝기·채도 단서는 HSV의 S·V 칸에 그대로 남는다. 그래서 확인된 것은 "조명 색조 몫이 작다"까지이고, 남은 색 신호가 옷 색 관계라고 단정할 수는 없다.
- **색 정보가 큰 몫이다**: CLIP 없이 색 히스토그램만으로 hard에서는 raw CLIP과 비슷하고(0.790/0.761 vs 0.786/0.769), random에서는 조금 낮다(0.798/0.772 vs 0.815/0.795).
- **색을 뺀 신호도 있다**: 흑백 CLIP도 hard AUC 0.71~0.72, FITB 28~32%로 우연보다 높다. 모양·무늬·질감 쪽 신호가 따로 있다.
- 두 신호를 합치면(CLIP + 색 히스토그램) 더 나은지는 재지 않았다.
- 여전히 남은 같은 사진 단서: 화질·압축·채도·밝기 같은 조명 색 말고 다른 단서는 대조하지 않았다.

## 해석과 한계

- hard에서도 우연보다 크게 높다 → 스타일 라벨이 같은 옷끼리도 "함께 입은 쌍"을 어느 정도 구분한다.
- **같은 사진 지름길 위험**: positive는 같은 사진에서 나와 조명·화질이 같다. 조명 색조 몫은 색 히스토그램 모델 기준으로 작다고 확인했다(위 표). CLIP 모델의 사진 전체 기준 보정은 돌리지 않았고, 밝기·채도·화질·압축 같은 다른 단서는 확인하지 않았다.
- **스타일 쏠림**: 표본의 53%가 스트리트라 hard negative도 대부분 스트리트 안에서 뽑혔다. 스타일별 수치는 n이 작은 스타일이 많아 이번에는 보지 않았다.
- **도메인 차이**: 착용 사진(사람이 입은 옷)으로 학습했다. 서비스 옷장은 Flat Lay·단독 사진이라 분포가 다르다. 검출 크롭만 바꿔도 AUC가 0.05 떨어졌다.
- **같은 인물·같은 코디의 다른 컷 누수**: 거의 같은 사진 묶음 기준(상의·하의 cosine 둘 다 0.95 이상)에 걸린 사진은 5,000장 중 6장뿐이었다. 같은 인물이나 같은 코디를 다른 각도로 찍은 사진은 이 기준으로 거의 걸러지지 않으므로 train/test에 걸쳤을 수 있고, 그만큼 점수가 부풀려졌을 수 있다(정도는 미측정).
- 다음 단계 판단 기준 `[초안]`: 이번 실험 설계 때 세운 기준(문서·회의 근거 없음). "LR hard FITB가 cosine보다 10%p 이상, hard AUC 0.65 이상이면 추천에 붙이는 후속을 제안" → hard AUC는 충족(0.77~0.79), FITB 차이는 7%p로 미충족.
