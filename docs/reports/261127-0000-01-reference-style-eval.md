## 요약

사용자가 모은 요즘 스타일 레퍼런스 사진 185장(핀터레스트 검색어 기준, 추구미 칸이 있는 174장)으로 추구미 7종을 다시 쟀다. **요즘 사진에서는 7종이 K-Fashion보다 훨씬 잘 맞았다.** 같은 사진 154장에서 5종과 비교하면 7종이 적중률·AUC 모두 조금 높지만(0.545/0.830 vs 0.515/0.821) 차이는 작다. 레퍼런스 절반과 K-Fashion으로 코디 문장을 골랐더니 레퍼런스 확인용 절반과 K-Fashion 확인용 모두에서 좋아졌다(단, 문장 후보는 레퍼런스 사진 전부를 보고 썼다). 예시 사진 평균 방식은 1위 적중률은 높지만 AUC가 낮다.

**주의**: 정답은 검색어 기준이라 섞였을 수 있다(미검증). 사진 전체(코디) 기준이다. 서비스는 옷 한 벌 기준이라 그대로 같지 않다.

## 측정 방법

- 수치 파일: `outputs/reference_eval/summary.json`(측정, 5종 행 포함), `tune_result.json`(문장 고르기). 레포에 안 올림
- 데이터: `data/reference_styles/`(레포 밖). 7종 칸에 1이 있는 사진 174장, 추구미별 20~40장(사진 하나가 여러 추구미일 수 있음). 하위 태그(`sub_tag`)는 기록만 하고 쓰지 않았다
- 스크립트
  - `scripts/eval_reference_styles.py`: 레퍼런스 사진 임베딩을 저장해 두고, 설정 파일 문장과 비교하는 방식(지금 방식)과 레퍼런스 사진 평균 임베딩과 비교하는 방식(예시 사진 방식)을 잰다
  - `scripts/tune_reference_prompts.py`: 문장 후보(`configs/style_prompt_pool.json`, 이번에 레퍼런스를 보고 21개 추가. **레퍼런스 사진 전부(다듬기용·확인용 모두)를 본 뒤 썼으므로 레퍼런스 확인용은 완전히 처음 보는 사진은 아니다.** K-Fashion 확인용은 독립)에서 스타일마다 4개를 고른다
- 지표: **1위 적중률**(1위가 정답 칸 중 하나면 맞음, 추구미별 평균), **AUC**(추구미 하나만 보고 정답 사진 점수가 더 높은지, 0.5 = 우연)
- 나누기: 레퍼런스는 하위 태그별로 반씩 나눠 다듬기용 95장 / 확인용 79장. K-Fashion은 이전과 같이 다듬기용(시드 42) / 확인용(시드 123, 시드 42 사진 제외)

## 결과

### 1. 레퍼런스 사진 174장 전체 (문장은 바꾸기 전)

| 설정 | 1위 적중률 | AUC | 우연 대비 배수 |
| --- | --- | --- | --- |
| 5종 (오피스만 있는 사진 제외 154장, 빈티지 레이어드 = Y2K/빈티지 또는 보헤미안) | 0.515 | 0.821 | 2.58 (우연 0.20) |
| 7종 처음 문장, **5종과 같은 154장** | 0.545 | 0.830 | 3.82 |
| 7종 처음 문장 `aesthetics_7.yaml` | 0.481 | 0.825 | **3.37** (우연 0.143) |
| 7종 K-Fashion으로 고른 문장 `aesthetics_7_tuned.yaml` | 0.459 | 0.810 | 3.21 |
| 7종 옷 한 벌 문장 `styles.yaml`(서비스) | 0.421 | 0.799 | 2.95 |

- K-Fashion에서는 7종 적중률이 0.30~0.36이었는데 요즘 사진에서는 0.48이다. **K-Fashion이 우리 7종을 잘 대표하지 못했다**는 앞선 추정(`261126-0310-01-style7-eval.md`)과 맞는다
- 추구미별(처음 문장, 적중률 / AUC): 미니멀 0.70/0.922, 캐주얼 0.10/0.687, 러블리/페미닌 0.65/0.953, 걸리시 스트릿 0.78/0.876, Y2K/빈티지 0.45/0.691, 오피스/클래식 0.10/0.805, 보헤미안 0.59/0.844. 캐주얼·오피스는 1위로 거의 안 나오고(5장씩), 스트릿으로 몰린다(54장)

### 2. 문장 고르기 (목표: 레퍼런스 다듬기용 + K-Fashion 다듬기용의 AUC 합)

| 문장 | 레퍼런스 확인용 79장 | K-Fashion 확인용 801장 |
| --- | --- | --- |
| 처음 문장 | 0.450 / 0.832 | 0.300 / 0.696 |
| **고른 문장 `aesthetics_7_ref.yaml`** | **0.480 / 0.854** | **0.349 / 0.716** |

(적중률 / AUC, K-Fashion 801장은 7종 연결 스타일이 있는 사진만)

- 확인용 두 묶음에서 모두 좋아졌다. 참고로 K-Fashion 확인용 5종은 0.459 / 0.701(1,101장, 5종 연결 스타일 기준)이다. 7종(801장, 7종 연결 스타일 기준)과 표본이 달라 직접 비교는 어렵고, AUC 차이(0.716 vs 0.701)도 작다
- 목표를 1위 적중률로 했을 때는 다듬기용만 크게 오르고(0.51 → 0.74) 레퍼런스 확인용은 그대로(0.450 → 0.448)였다. 사진이 적어 적중률은 흔들려서 AUC를 목표로 했다
- 바뀐 문장: 걸리시 스트릿에 블록코어·고프코어, 오피스에 "셔츠 위 니트 + 와이드 슬랙스", 보헤미안에 웨스턴·모리걸, 러블리에 발레·코케트, 캐주얼에 데님 문장이 들어갔다. Y2K/빈티지는 레퍼런스를 보고 쓴 문장(브라운 니트 조끼, 플레어 데님 등)이 아니라 K-Fashion 쪽(펑크·키치) 문장이 골라졌다. 전체 174장 기준 Y2K/빈티지는 1위가 6장뿐(적중률 0.12)이라 AUC(0.816)는 올랐지만 1위로는 잘 안 나온다

### 3. 예시 사진 방식 (스타일별 레퍼런스 평균 임베딩)

| 방식 | 1위 적중률 | AUC |
| --- | --- | --- |
| 자기 자신 빼고 나머지 평균 (174장) | 0.577 | 0.732 |
| 다듬기용 반으로 평균 → 확인용 반 79장 | 0.549 | 0.750 |
| (비교) 고른 문장, 확인용 79장 | 0.480 | 0.854 |

- 1위 적중률은 예시 사진이 높고, AUC는 문장이 훨씬 높다. 스타일마다 점수를 따로 매기는 서비스(태깅 v1)에는 AUC가 맞는 지표라 **문장 방식을 유지**한다
- 예시 사진 방식을 서비스에 쓰려면 레퍼런스 평균 임베딩을 레포에 저장해야 한다. → 쓰지 않기로 함(11/27)
