# K-Fashion 평가를 스타일 특징 프롬프트로 재실행, 비교

- 일시: 2026-11-01 00:02
- 작성: AI 파트
- 관련 TODO: `docs/todo/kfashion-style-eval.md`
- 관련 기능 ID: F-203, F-302

## 요약

23종 평가를 스타일 특징을 넣은 프롬프트로 다시 돌렸다. 균형 정확도는 19.7%에서 23.0%로 올랐지만 안정적으로 구분한다고 보기는 어렵다. 두 프롬프트의 예측이 같은 이미지는 1,150장 중 238장(21%)뿐이어서, 문장을 바꾸면 답이 크게 달라진다.

## 변경 내역

- `configs/kfashion_styles.yaml`: 프롬프트를 `name_only`와 `described` 세트로 분리. `described`는 스타일당 3문장
- `scripts/eval_kfashion_styles.py`: `--prompt-set` 추가, 결과를 세트별 폴더에 저장
- `docs/04-kfashion-validation.md`: 실행 방법에 프롬프트 세트 추가

- 쏠림은 줄었지만 사라지지 않았다. 클래식 예측은 376번에서 7번으로 줄었고, 대신 모던 261번, 페미닌 205번, 아방가르드 163번에 몰린다. 이 셋의 예측이 맞은 비율은 10~11%이다.
