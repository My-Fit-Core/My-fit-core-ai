## 요약

기획 합의에 따라 추구미 5개를 "기본 스타일"로 재정의했다. Y2K를 스트리트로 바꾸고, 캐주얼(무지 기본템)과 스트리트(오버핏·그래픽·로고·카고·캡)의 프롬프트가 같은 아이템을 쓰지 않게 다시 썼다. 재측정해 보니 우리 스트리트는 K-Fashion 힙합·스포티와 맞고, K-Fashion 스트리트는 일상복에 가까워 캐주얼과 맞았다. 이에 맞춰 K-Fashion 연결을 바꾸고 보정 고정값을 다시 계산했다. 남은 약점은 캐주얼↔미니멀 혼동이다.

## 변경 내역

- `configs/aesthetics.yaml`
  - `y2k` → `street`(스트리트), 캐주얼 프롬프트 재작성. 캐주얼: 티셔츠·니트·셔츠·일자 청바지·치노·운동화, 스트리트: 후드·맨투맨·카고 팬츠·캡
  - K-Fashion 연결(잠정): 스트리트 → 힙합·스포티, 캐주얼 → 스트리트·톰보이
  - `outfit_v2` 세트 삭제(issue #42에서 채택하지 않음)
  - 보정 고정값 재계산
- `scripts/eval_aesthetics_on_kfashion.py`
  - 기본 프롬프트 세트를 `outfit` 하나로
  - 연결 스타일이 없는 추구미는 적중률에서 제외(None)
  - 혼동 지표(`CONFUSION_PAIRS`): 캐주얼↔스트리트, 캐주얼↔미니멀
- `tests/test_eval_aesthetics_on_kfashion.py`: 연결 없음 허용, 적중률 제외, 혼동 지표 테스트
- `docs/02-specs.md`: 기본 스타일 5개, 마이크로 트렌드는 2차 로드맵, 우리 스트리트와 K-Fashion 스트리트의 차이
- `docs/04-kfashion-validation.md`: 기존 Y2K 연결 표를 이전 기록으로 표시, 기본 스타일 결과 추가
- `docs/todo/aesthetic-display.md`: Y2K 질문 닫음

## 결과·측정치

조건: K-Fashion Validation 23종 × 50장 = 1,150장, 시드 7과 42, Windows CPU(시드당 약 6분). 결과 폴더는 `outputs/base_styles/seed<시드>/`. 재현: `python scripts/eval_aesthetics_on_kfashion.py --seed 42 --output-dir outputs/base_styles/seed42`

새 연결의 적중률은 재측정 없이 같은 점수로 다시 계산했다. 점수 계산은 결정적이라 위 명령을 다시 돌리면 같은 값이 나온다.

### 혼동 지표 (새 연결, 시드 7 / 42, 보정 전 → 후)

| 쌍 | 상대 스타일 사진 중 캐주얼 1위 | 캐주얼 스타일 사진 중 상대 1위 | 1위가 둘 중 하나일 때 2위가 나머지 |
| --- | --- | --- | --- |
| 캐주얼↔스트리트 | 6~10% → 16% | 4~5% → 5~9% | 25~27% → 29~33% |
| 캐주얼↔미니멀 | 2% → 7~12% | **54~57% → 38~41%** | 34~37% → 41~42% |

- "상대 스타일 사진"은 스트리트면 힙합·스포티, 미니멀이면 모던·소피스트케이티드다. "캐주얼 스타일 사진"은 K-Fashion 스트리트·톰보이다.
- 캐주얼↔스트리트는 아이템을 나눈 덕분에 서로 1위를 빼앗는 경우가 적다.
- 캐주얼 스타일 사진의 절반 이상이 미니멀로 간다. 보정하면 줄지만 여전히 약 40%다. 무지·기본템 쪽은 미니멀과 구분이 어렵다.

- 캐주얼↔미니멀 혼동: 캐주얼 스타일 사진의 약 40%가 보정 후에도 미니멀로 간다. 프롬프트 조정이나 linear probe(issue #34)에서 다룬다.
- 마이크로 트렌드(Y2K 등)는 2차 로드맵. 이미지를 직접 모아야 한다.
