## 요약

YOLO(DeepFashion2)가 찾은 옷을 잘라 FashionCLIP zero-shot으로 부위와 K-Fashion 카테고리 21종을 판정했다. 부위는 YOLO가 전체적으로 가장 정확하지만(89.7%) 아우터는 46%에 그쳤고, FashionCLIP은 아우터를 69%까지 맞혔다. 세부 카테고리 1위 정확도는 53~55%로 약하고, 상위 3개 안에는 73%가 들어간다. 마스크 밖을 지운 사진이 하의에서 특히 나아 기본 자르기 방식으로 정했다.

## 변경 내역

- `scripts/eval_category_kfashion.py`: 검출된 옷을 박스·마스크 두 방식으로 잘라 부위(part4, 카테고리 경유)와 카테고리를 판정하고 YOLO 부위와 비교
- `scripts/eval_segmentation_kfashion.py`: `parts_from_label`이 라벨의 카테고리도 돌려줌
- `tests/test_eval_category_kfashion.py`: 카테고리 목록, 자르기, 요약, 조합 규칙 테스트
- (추가 측정) `scripts/eval_category_kfashion.py`: 조합 규칙(`combine_part`)과 아우터 오판정 수(`false_outer`) 출력
- `docs/02-specs.md`: 태깅 입력 방식 반영

## 결과·측정치

조건: 검출·누끼 평가(`261108-0305-01-detection-segmentation-poc.md`)와 같은 50장(시드 42), 부위 104개 중 검출된 97개(상의 37, 하의 47, 아우터 13). Windows CPU, 약 2분. 결과 폴더는 `outputs/category_poc/`.

- 자르기: `box`는 검출 박스로 자른 사진, `masked`는 YOLO 마스크 밖을 흰색으로 지운 뒤 박스로 자른 사진
- 부위 판정: `part4`는 부위 4개 문장 중 1위, 카테고리 경유는 카테고리 21개 중 1위의 부위
- 프롬프트: `a photo of {영어 표현}`. 영어 표현은 작성자가 골랐다(스크립트의 `CATEGORIES`).

### 부위 정확도

| 정답 부위 | n | YOLO | part4 (box / masked) | 카테고리 경유 (box / masked) |
| --- | ---: | ---: | ---: | ---: |
| 전체 | 97 | **89.7%** | 79.4% / 85.6% | 85.6% / 87.6% |
| 상의 | 37 | 91.9% | 83.8% / 86.5% | 89.2% / 86.5% |
| 하의 | 47 | **100%** | 80.9% / 91.5% | 87.2% / 93.6% |
| 아우터 | 13 | 46.2% | 61.5% / 61.5% | **69.2% / 69.2%** |

- FashionCLIP(카테고리 경유, box)은 아우터가 아닌 옷 5개를 아우터로 판정했다.

### 카테고리 정확도 (21종 중 1위 / 상위 3개)

| | box | masked |
| --- | ---: | ---: |
| 전체 | 52.6% / 73.2% | 54.6% / 73.2% |
| 상의 | 40.5% / 59.5% | 37.8% / 54.1% |
| 하의 | 63.8% / 80.9% | 72.3% / 87.2% |
| 아우터 | 46.2% / 84.6% | 38.5% / 76.9% |

- 자주 헷갈린 쌍(masked): 티셔츠 → 블라우스 8번, 티셔츠 → 니트웨어 4번, 팬츠 → 스커트 4번, 재킷 → 코트 2번
- 아우터 중 가디건·재킷은 안에 입은 옷 때문에 블라우스로 판정되기도 했다.
- 4개 부위는 라벨에 카테고리가 비어 있어 오답으로 계산했다. 카테고리 정확도는 1~4%p 낮게 나왔을 수 있다.
- 아우터가 13개뿐이라 아우터 수치는 흔들림이 크다.

## 주요 결정

| 결정 | 근거 | 대안과 버린 이유 |
| --- | --- | --- |
| 태깅 입력은 마스크 밖을 흰색으로 지운 사진(`masked`) | 부위·카테고리 정확도가 전체적으로 같거나 높고, 하의는 카테고리 63.8% → 72.3%로 크게 오름 | `box`: 배경과 다른 옷이 섞여 하의 판정이 흔들림 |

## 추가 측정: 부위 조합 규칙 (300장, 2026-11-08 03:20)

조합 규칙은 "YOLO 부위를 기본으로 쓰고, FashionCLIP(카테고리 경유, masked)이 아우터라고 하면 아우터"다. 50장에서 아우터가 13개뿐이어서 다른 표본으로 다시 쟀다.

조건: 시드 7, 300장(시드 42의 50장과 겹치는 이미지 0장), 정답 부위 624개 중 검출된 584개(놓침 40개). Windows CPU, 약 6분. 결과 폴더는 `outputs/category_poc_seed7_300/`. 재현: `python scripts/eval_category_kfashion.py --images 300 --seed 7 --output-dir outputs/category_poc_seed7_300`

| 정답 부위 | n | YOLO | FashionCLIP 카테고리 경유 | 조합 규칙 |
| --- | ---: | ---: | ---: | ---: |
| 전체 | 584 | **92.8%** | 85.3% | 87.8% |
| 상의 | 239 | **93.7%** | 83.7% | 82.4% |
| 하의 | 278 | **99.3%** | 91.4% | 93.5% |
| 아우터 | 62 | 61.3% | 69.4% | **85.5%** |
| 원피스 | 5 | 80% | 20% | 60% |

- 아우터가 아닌데 아우터로 판정한 수: YOLO 8개, FashionCLIP 50개, 조합 규칙 53개(상의 35, 하의 17, 원피스 1)
- YOLO 대비 조합 규칙은 15개를 고치고 44개를 망쳤다.
- 카테고리 정확도(masked)는 1위 51.4%, 상위 3개 75.3%로 50장 결과와 비슷하다.
- YOLO 아우터 정확도는 50장의 46%보다 높은 61%다. 50장의 아우터 13개로는 흔들림이 컸다.
- FashionCLIP이 하의를 아우터로 판정한 17개의 원인은 확인하지 않았다(미확인).

### 결정

| 결정 | 근거 | 대안과 버린 이유 |
| --- | --- | --- |
| 부위 판정은 YOLO 단독 | 전체 92.8%로 가장 높음 | 조합 규칙: 아우터는 85.5%로 오르지만 YOLO 대비 고침 15개, 망침 44개로 전체가 87.8%로 낮아짐. FashionCLIP 단독: 85.3% |

### 제안: 등록 시 사용자 확인

자동 판정만으로는 부족하므로, 옷 등록 화면에서 판정 결과를 사용자가 확인·수정하는 단계를 제안한다. 화면·흐름은 프론트·백엔드와 합의가 필요하다.

- 부위: 전체 92.8%지만 아우터는 61%다. 판정 부위를 기본값으로 보여주고 바꿀 수 있게 한다.
- 카테고리: 1위가 약 52%, 상위 3개가 약 75%다. 상위 3개를 후보로 보여주고 고르게 한다.
