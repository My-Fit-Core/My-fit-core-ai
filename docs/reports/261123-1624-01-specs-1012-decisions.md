## 어긋남 (보고)

1. `app/schemas.py` v0과 합의 내용이 다르다: bbox `list[int]`(합의는 정규화 float), `category` 한 필드, `status` pending/running/done/failed, `error: str`(합의는 결과 상태 3종과 `errors[]`). `client_item_key`와 누끼 업로드 URL 필드가 없다. → T6
2. 작업 상태 4종(대기·진행중·완료·실패)과 결과 상태 3종(`succeeded`/`partial_failed`/`failed`)이 v0 스키마에서는 `status` 하나에 섞여 있다. 두 필드로 나눌지 T6에서 확인이 필요하다.
3. `configs/aesthetics.yaml` `categories`의 대분류 이름(`outer`, bag을 포함한 `accessory`, `dress`)이 백엔드 6종과 다르다. → T2
4. 백엔드 6종에는 `shoes`, `bag`, `accessory`가 있지만 현재 검출기(DeepFashion2 YOLO, 13종 의류 클래스)에는 해당 클래스가 없다(plan §9). → T2에서 MVP 범위 결정
5. 긴 변 2048px은 코드(`app/pipeline/image_input.py`)에서 상수로 쓰지만 plan §8은 유지 여부를 미정으로 둔다. specs에는 "현재 구현값, 유지 여부 `TBD`"로 적었다.
6. `AnalyzeRequest.callback_url` 설명이 아직 "결과 전달 방식 TBD"다. 합의로 콜백 `[확인]`이 됐으니 T6에서 정리한다.
7. 기존 specs §6 날씨 값(온도·습도·강수확률·강수형태)에 풍속이 없었다. 회의 답변에서 추가됐다.
8. `requirements.txt`는 고정됐지만 `requirements-ml.txt`(torch, ultralytics 등)는 버전이 고정돼 있지 않다. 안건 10이 ML 의존성까지 포함하는지 확인이 필요하다.
9. 회의 날짜 표기가 다르다: 파일 이름과 제목은 `meeting-decisions-1013`(10/13 월요일 회의)인데 plan·tasks는 "10/12 회의"로 적는다. 같은 회의인지 확인이 필요하다.
10. `03-product-plan.md`, `01-folder-architecture.md`의 TPO·"15대 추구미" 표현이 남아 있다. → T22
