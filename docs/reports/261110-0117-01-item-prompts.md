## 요약

서비스 API는 옷 한 벌마다 추구미 점수(`aesthetic_scores`)를 낸다. 그래서 옷 한 벌용 프롬프트 `prompts.item`을 기본 스타일 5개에 대해 작성하고, K-Fashion 사진을 YOLO 마스크로 잘라낸 옷 단위로 코디용(`outfit`) 프롬프트와 비교했다. 평균 적중률은 두 세트가 비슷하지만(36~39%), item은 페미닌·캐주얼을, outfit은 미니멀·빈티지 레이어드를 더 잘 맞혔다. item 세트는 미니멀 쏠림이 없다. 대신 옷 종류에 따른 쏠림이 강하다(청바지 → 캐주얼 84~88%, 후드티 → 스트리트 80~90%). 옷 한 벌 판정에는 `prompts.item`을 쓰고, 보정은 적용하지 않는다.

## 변경 내역

- `configs/aesthetics.yaml`
  - `prompts.item`: 기본 스타일당 4문장. 캐주얼(티셔츠·니트·일자 청바지·셔츠)과 스트리트(후드·카고 팬츠·맨투맨·바시티 재킷)는 옷 종류를 나눔. 캐주얼과 미니멀(슬랙스·블레이저·코트·슬립 원피스)도 되도록 겹치지 않게 함. 신발·모자는 검출 대상이 아니라 뺌
  - `calibration_item`: 옷 한 벌용 보정 고정값. 기록만 하고 적용하지 않음(`applied: false`)
- `scripts/eval_item_aesthetics_kfashion.py`: 옷 단위 추구미 점수, 연결 적중률, 옷 카테고리별 1위 분포
- `scripts/eval_segmentation_kfashion.py`: `pick_samples`에 `min_parts`, `per_style`(스타일별 같은 수) 옵션. 기본 동작은 그대로
- 테스트: 옷 단위 점수 묶기, 카테고리별 집계, item 프롬프트 수와 캐주얼·스트리트 옷 종류 분리, item 보정값 형식
- `docs/02-specs.md`: 코디 사진과 옷 한 벌의 추구미 점수 방식 구분
- 같이 한 일: #41 파이프라인을 PR #48로 develop에 병합(#41은 Flat Lay 비교가 남아 열어 둠)

## 결과·측정치

조건: K-Fashion Validation 23종 × 20장 = 460장(시드 7, 42), 검출되어 정답 박스와 짝지어진 옷 644벌 / 649벌(놓침 38 / 35). 옷은 YOLO 마스크 밖을 흰색으로 지우고 박스로 자름(카테고리 PoC와 같음). Windows CPU, 시드당 약 15분. 결과 폴더는 `outputs/item_aesthetics/seed<시드>/`. 재현: `python scripts/eval_item_aesthetics_kfashion.py --seed 42`

정답: 옷이 나온 원본 사진의 주 스타일이 추구미의 연결 스타일(`kfashion.styles`)에 속하면 맞는 답이다.

### 연결 적중률 (보정 후, 시드 7 / 42)

| 기본 스타일 | outfit 프롬프트 | item 프롬프트 |
| --- | ---: | ---: |
| 페미닌 | 40% / 39% | **54% / 44%** |
| 스트리트 | 49% / 44% | 49% / 52% |
| 미니멀 | **39% / 47%** | 20% / 29% |
| 빈티지 레이어드 | **45% / 42%** | 34% / 29% |
| 캐주얼 | 21% / 15% | **26% / 35%** |
| 평균 | 38.8% / 37.2% | 36.8% / 37.6% |

보정 전 평균은 outfit 36.5% / 37.9%, item 35.8% / 36.7%다.

### 점수 분포 (전체 평균, 시드 42)

| 프롬프트 | 페미닌 | 스트리트 | 미니멀 | 빈티지 레이어드 | 캐주얼 |
| --- | ---: | ---: | ---: | ---: | ---: |
| outfit | 0.149 | 0.112 | **0.335** | **0.296** | 0.107 |
| item | 0.165 | 0.221 | 0.146 | 0.191 | **0.276** |

### 옷 카테고리별 1위 스타일 (보정 후, 시드 7 / 42)

| 옷 카테고리 | outfit 프롬프트 | item 프롬프트 |
| --- | --- | --- |
| 청바지 | 캐주얼 81% / 88% | 캐주얼 88% / 84% |
| 후드티 (시드 42, 10벌) | 스트리트 80% | 스트리트 90% |
| 점퍼 | 스트리트 53% / 40% | 스트리트 84% / 67% |
| 블라우스 | 페미닌 44% / 49% | 페미닌 63% / 57% |
| 티셔츠 | 미니멀 33% / 40% | 캐주얼 46%·스트리트 38% / 스트리트 43%·캐주얼 40% |
| 팬츠 | 미니멀 42% / 44% | 미니멀 37% / 40% |
| 재킷 | 빈티지 레이어드 61% / 44% | 빈티지 레이어드 51% / 37% |
| 니트웨어 | 빈티지 레이어드 59% / 미니멀 43% | 빈티지 레이어드 38% / 캐주얼 40% |
| 스커트 | 빈티지 레이어드 42% / 48% | 빈티지 레이어드 34% / 42% |

- 청바지와 후드티는 프롬프트 세트와 관계없이 한 스타일로 몰린다. 옷 종류가 판정을 크게 좌우한다.
- K-Fashion에는 블레이저 카테고리가 따로 없어(재킷에 포함) 블레이저만 따로 집계하지 못했다.
- 티셔츠는 스트리트 item 프롬프트에 없는데도 item 세트에서 캐주얼과 스트리트로 갈린다.

### 옷 한 벌용 보정 고정값 (시드 42)

| 페미닌 | 스트리트 | 미니멀 | 빈티지 레이어드 | 캐주얼 |
| ---: | ---: | ---: | ---: | ---: |
| 0.165 | 0.221 | 0.146 | 0.191 | 0.276 |

- 시드 7과의 차이가 최대 0.034(캐주얼)다. 코디용 보정값(차이 0.01)보다 불안정하다. 표본이 460장으로 적다.
- 보정해도 1위가 거의 바뀌지 않는다(시드 42 캐주얼 1위 181 → 158 등).

### 한계

- **정답이 코디 단위 라벨이다.** K-Fashion 스타일은 사진(코디) 전체에 붙은 라벨이라, 같은 사진의 모든 옷이 같은 정답을 받는다. 예를 들어 힙합 코디 안의 무지 청바지도 "스트리트가 정답"으로 채점된다. 옷 한 벌의 실제 스타일과 다를 수 있어 옷 단위 적중률은 낮게 나온다. 코디 사진 전체로 판정한 적중률(#44: 46.6% / 49.6%)과 직접 비교하지 않는다.
- 착용 사진에서 잘라낸 옷이다. 서비스 입력인 Flat Lay 사진에서는 다시 확인해야 한다.
- 프롬프트 영어 표현은 작성자가 골랐다.

## 주요 결정

| 결정 | 근거 | 대안과 버린 이유 |
| --- | --- | --- |
| 옷 한 벌 판정은 `prompts.item` | 평균 적중률은 outfit과 비슷하고, 미니멀 쏠림이 없으며, 옷 한 벌을 가정한 문장이라 서비스 입력과 맞음 | `prompts.outfit`: 코디를 가정한 문장이고 미니멀·빈티지 레이어드로 쏠림 |
| item 보정값은 configs에 기록만, 적용 안 함 | 보정해도 1위가 거의 바뀌지 않고, 시드 간 차이가 최대 0.034로 불안정 | 적용: 효과가 작고 값이 표본에 따라 흔들림 |
| 옷 종류 쏠림은 MVP에서 유지 | 추천에서 코디 점수를 옷 점수의 합으로 쓰면, 기본템(청바지 등)은 여러 스타일 코디에 두루 쓰이는 구조라 받아들일 수 있음 | 카테고리별 평균을 빼는 보정: 후속 과제 |
