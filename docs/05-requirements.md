### OnBoarding-003 — 비주얼 무드보드 카드 탐색

| 항목 | 내용 |
|------|------|
| **기능명** | 비주얼 무드보드 카드 탐색 |
| **기능 ID** | OnBoarding-003 |
| **상세 설명** | AI 학습용 데이터셋에서 5개 추구미별 대표 코디 이미지를 각 3~4장 선별, 총 15~20장의 무드보드 카드 구성. 각 카드에 추구미 라벨을 사전 매핑. 사용자가 취향에 맞는 이미지를 선택하면 선택 카드의 라벨을 집계하여 메인/보조 추구미를 결정. 결과가 의도와 다를 경우 결과 화면에서 직접 재선택 가능. |
| **정보구조** | 앱 최초 실행 > 온보딩 > 추구미 인지 여부 선택 > 몰라요 > 무드보드 |
| **유저플로우** | 무드보드 카드 노출 → 마음에 드는 코디 선택 → 선택 이미지의 사전 라벨 집계 → 추구미별 선호 점수 계산 → 메인/보조 추구미 결정 → 결과 확인·수정 → OnBoarding-004 이동 |
| **비고** | **동점 처리**: 메인/보조 추구미 산정 시 동점 발생 시 Tie-break 카드(추가 대표 이미지)를 노출하여 추가 선택으로 최종 순위 결정 |
